看这张参考图，只写**同一个人物**的外形与服装细节，1~2 句、不分行、不要标题：

- 人物外形：脸型 / 发型发色 / 体型比例 / 整体气质；
- 服装：款式 / 配色 / 材质 / 配饰 / 遮盖范围。

要求：
- 参考图可能是多视图角色设定图（三视图 / 四视图）：只汇总这一个人物的外形与服装，不要按视图罗列，不要写姿态、机位、镜头、分镜、场景、背景、画风与光线。
- 只写图上看到的事实，不要编造故事、动作或情节。
- 语言默认中文，直接输出这一段文字。
