# H3 连续多段合成（Continuous Multi-Segment Synthesis）

把连续的文生 / 图生 / 首尾帧段合并成**一次** ref2va 运行：各段分镜关键帧按累计起点钉在对应帧号，
`fl2v` 段的尾帧钉在终点。适合节奏紧凑、镜头间无需独立参考素材的连续片段，减少跨段接缝与运行次数。

## 适用模式

`t2v` / `i2v` / `fl2v`（无自带参考素材、无源视频）。带参考素材或源视频的段会自动退回逐段执行。
选中本技能后，导演按「分块秒数」预算把连续兼容段合并成一块；未选中的段仍各自逐段生成。

## 合并与提示词

由配方「分块秒数」（`shared.chunk_sec`，缺省 15）控制：连续兼容段总时长 ≤ 该值时合并成一块，`0` = 关闭（纯逐段）。
多段提示词按 `[Shot N] At <时间戳> cut... <原文>` 顺序机械拼接（确定性、无 LLM），各段内容与顺序原样保留。
