# Neo H3 Segment Run

**节点键**：`NeoH3SegmentRun` · **显示名**：Neo H3 Segment Run (单段生成/重生成)

## 用途
单段生成 / 重生成：只跑配方里的某一段，可选用成片结果里的前后真实帧当锚点，换种子重生成该段。
走执行队列，产物可写回配方「结果」区。

## 输入
| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `recipe` | Combo | 必需。`video_director` 配方名。 |
| `segment` | INT | 必需。配方里的段号（1 基）。 |
| `anchors` | Combo | 必需。用成片里的哪些真实帧当锚点：`两端锚点` / `只钉首帧` / `不用锚点`；配方还没有成片时自动降级为不用锚点。 |
| `seed` | INT | 必需。`-1` = 用配方该段的 seed；换种子重生成时填 `≥0`。 |
| `record` | BOOLEAN | 必需。开 = 产物同时写进配方「结果」区；关 = 只出 VIDEO。 |
| `steps` / `preview` / `continuity` / `context_frames` | 可选 | 覆盖该段的采样与连续性设置。 |
| `film` | STRING | 可选。成片文件名（配方「结果」区里的名字）：取其中的前后真实帧当锚点；空 = 用当前记录的最新成片。 |

## 输出
| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `video` | VIDEO | 该段生成结果，接 SaveVideo 预览，或回灌导演节点。 |

## 典型接法
导演节点整片生成后 → 选配方 + 段号 + 换种子 → 只重跑这一段 → 在编辑器里替换该段。

## 常见问题
- 锚点没生效：配方还没有成片记录，先整片生成一次。
- 想整片重做：用 Neo H3 Video Director，本节点只处理单段。

## 整条流程
导演节点先整片生成一次（配方「结果」区留下成片）→ 本节点选配方 + 段号 + 换种子
→ 从成片取前后真实帧当锚点 → 只重跑该段 → 在导演编辑器里替换该段。

## 相关节点
- **Neo H3 Video Director**：整片生成与段管理入口。
- **Neo H3 Add Context**：单段续接用的跨段上下文节点。
