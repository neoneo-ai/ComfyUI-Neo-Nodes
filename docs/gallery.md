# Neo Gallery - 侧边栏素材系统

ComfyUI 右侧边栏中的图片/视频/音频浏览与管理面板：内置预设库 + 多个用户自定义目录。

![Neo Gallery 素材面板](assets/images/neo-gallery.png)

## 浏览与导航

- **侧边栏集成** - 作为右侧边栏标签页打开，无需离开画布
- **卡片布局** - 卡片瀑布式排布（最短列装箱：按条目顺序逐个放进当前最矮的一列），高低混合自动填空、不留整列空白；同一目录内的子目录卡与图片卡共用一个瀑布流（目录卡在前，图片卡接着装箱填空），衔接处不留空；素材缩略图卡高度随图片朝向自适应（竖图→高卡 3:4、横图→矮宽卡 3:2、方图→方卡）；目录卡按封面瓦片的合成比例取高（双竖图并排→宽 3:2 卡、横图单张→矮宽 3:2 卡），与单图素材卡天然不同，同朝向封面恰好填满各自瓦片不裁切；封面最多两张：竖/方图左右并排且顶部锚定（减少切头），横图只留一张（双图堆叠太高）；纯音频目录显示音频瓦片，空/失效封面显示通用占位瓦片
- **面包屑导航** - 多级子目录层级清晰，随时返回上级
- **前进/后退按钮** - 顶部标题旁可沿浏览轨迹前进、后退（浏览器 Back 同样走这条轨迹；Alt+Left / Backspace 仍为返回上级目录）
- **按时间排序** - 按文件修改时间排序，可切换新旧顺序并记住偏好
- **滚动位置记忆** - 自动保存每个目录的浏览位置，切回时原地恢复
- **懒加载** - 列表分页渲染、封面滚动进入视口才加载，大图库依然流畅

![Neo Gallery 侧边栏浏览](assets/images/gallery-sidebar.png)

## 媒体与搜索

- **图片、视频与音频** - 支持 jpg/png/webp/gif 等图片、mp4/webm 等视频以及 wav/mp3/m4a/flac/ogg 等音频的混合浏览；音频卡片显示波形，点击 ▶ 试听（首次播放解码出真实峰值）
- **缩略图缓存** - 首次访问自动生成缩略图，再次打开即秒出
- **竖图不切头** - 素材缩略图卡与目录卡都按图片朝向自适应高度（见「卡片布局」，目录卡取封面瓦片合成比例）；卡片内竖图（高≥宽）顶部锚定，裁掉底部而不是头部
- **关键词搜索** - 跨目录搜索文件名及同名 `.txt` 描述文件的内容
- **生成素材** - 搜索框旁「🖼️ 生成素材」打开小窗（同导演配方窗口：不加背景遮罩、标题栏可拖窗口），纯提示词一键生成新素材（默认 Krea2 文生图，可切换其他纯文生图技能并记住上次选择）；可展开「自定参数」临时选主模型 / LoRA / 宽高比 / 最长边（类似节点上接模型，不写回全局设置），满意的组合可一键「保存为新技能」（名称自动生成 = 主模型名+LoRA 名，比例 / 最长边随所选值保存，其余设置沿用当前技能）；「✨ 增强」为 agent 式增强区（output 上 + quick input 下双框，仿 NeoPromptAgent 节点）：quick input 输描述或修改指令，选增强技能（只列图像增强类技能、默认自动路由、记住上次选择）后点 ✨ 流式增强；复用节点 agent 逻辑（所选技能的 skill.md 作系统提示词 + 按需读引用文件），正文写入 output 框（思考过程 / 流程状态实时显示在 output 上方临时面板，与节点共用），成功后 quick input 清空、有已有提示词时新指令按分隔线拼接；quick input 与 output 各有独立的命令终端式 ↑/↓ 历史（各自框内召回：快捷输入记之前用过的快捷输入，output 记生成实际用过的最终提示词，localStorage 持久化）；生成用 output 内容作最终提示词（为空回退 quick input）；产物落 `Output/NeoAgent/<日期>/`，成功后可一键跳到落盘目录，不满意可一键删除结果图；llm-chat 式布局：🎲 随机填入一条（混合池抽样）、▾ 运行时随机设置（启用后「生成」改为从节点同池随机抽 N 张批量逐张生成、取消保留已生成的，配方不入池，状态 localStorage 持久化）、☰ 预设列表（搜索 + 点击填入 output 框，无配方条目）浮出在 output 框右下角；增强技能下拉 + ✨ 增强集成在 quick input 内部底边工具栏；quick input 占位符随聚焦轮播使用提示
- **拖放到节点** - 直接把图片/视频/音频卡片拖到画布上对应的 LoadImage / Load Video / LoadAudio 节点即可写入（自动复制到输入目录），命中时节点高亮；图片卡也可直接拖到「宫格图拆分」节点写入其 filename 输入；载荷类型与目标节点不符时不写入

![灯箱查看器（缩放/平移 + 提示词侧栏）](assets/images/gallery-lightbox.png)

|------|------|
| ⧉ Copy | 复制当前图片到剪贴板 |

## 文件管理与目录

- **删除** - 直接删除素材中的媒体文件；presets 内置库只读保护，防止误删
- **多选批量删除** - 素材卡左上角勾选框可多选（Ctrl+A 全选当前视图、Esc 清空），底部操作条「删除」仅删除勾选项并先弹确认；有勾选时卡片 ⋯ 菜单的删除项也变为「删除已选素材（N）」走批量删除；presets/lora/C站收藏/远程 OSS 来源不显示勾选框且不可删。操作条另有「新建导演配方」：把选中图片逐张设为各段首帧建 f2v 配方
- **LoRA 打标** - 可写的叶子图片目录（Input / 自定义目录）卡片右上角显示 ⋯ 按钮，点开打标弹窗：填触发词（按文件夹名全拼连写自动建议，过短时随机非词兜底），可选先自动标准化目录（**先整目录备份到 `<目录>.bak`**，再 HEIC→PNG + `001.png`... 顺序编号，同名 `.txt` 跟随移动；HEIC 转换依赖可选的 `pillow-heif`）；随后复用现有 LLM（本地 GGUF / 远程 API）逐张生成标准化标签 `.txt`（SSE 进度，单张失败不中断整批；弹窗实时显示当前图片与标签结果，随帧自动切换）
- **自定义目录** - 在设置中添加本地或网络路径；「Manage Directories」弹窗内每行支持 ↑↓ 排序、👁 隐藏/恢复（隐藏的目录保留在配置里但不再列入素材库）、✕ 删除
- **多源汇总** - 所有目录统一入口浏览，互不干扰
- **StoryBoard / CharacterSheet 主目录** - 可浏览的 output 子目录：`output/StoryBoard/`（StoryBoard）与
  `output/CharacterSheet/`（CharacterSheet）。
  首页不显示卡片，经生成结果区 / 素材卡菜单的「直达」入口或深链（`dir_name=StoryBoard|CharacterSheet`）进入，
  生成的角色图 / 分镜图按日期落在 `<日期>/` 子目录；
  每一层（含中间目录）的卡片用该层自己的前两张媒体作封面（图片 > 视频 > 音频优先，走 `/neo_gallery/thumbnail` 缓存）；
  目录内另有只读的 **Cloud Presets** 入口（远端预设缓存落 `presets/<远端目录>/`），
  `Grid/presets/**`、`Character/presets/**` 与 Cloud Presets 一样不可删除
- **最近更新优先** - 插件自己写入的三个目录（生成结果 `Output`、归档的 `Grid` / `Character`）内，
  各层子目录卡都是最新写在前的，**封面在同类型内也取最新的两张**（图片 > 视频 > 音频优先，不再固定显示最早的那两张）；
  其余目录（自定义 / Presets / Lora / Input / 远端预设）保持原有顺序与封面选取

## Civitai LORA 示例缓存（访问时自动抓取）

「Manage Directories」弹窗底部的 **Civitai LORA Examples** 区可把 C 站（civitai.com）的 LORA
示例图与提示词抓取进素材库。无需手动同步——打开素材面板的「Lora」目录时，未缓存的 LORA 会自动进入
后台抓取队列：

- **启用 C 站 LORA**（总开关，默认关闭）- 关闭时不会注册、展示或抓取任何 C 站 LORA 示例；勾选后
  才会按所选目录自动获取。开关状态保存在 `configs/gallery_settings.json`
- **Civitai API KEY** - 粘贴你在 civitai.com 的 API KEY 后点「Save API KEY」；KEY 仅保存在本机
  `gallery_settings.json`（不入库），保存后以脱敏形式显示。未配置 KEY 时，已选 LORA 目录仍会以
  「需要配置 API KEY」角标展示在素材面板中，但不会联网抓取
- **测试 C 站连通性** - C 站对网络有要求（多数环境需要代理）。点击后会请求 `GET /models?limit=1`
  （最长 20 秒），返回：延迟、是否可达、以及已保存的 KEY 是否被接受。区分「无法连接 Civitai
  （需要代理）」与「API KEY 被拒绝 HTTP 401/403」两类问题。抓取队列遇到无法连接时会提前中止本批，
  并在状态栏显示网络错误提示
- **Select LORA Directories** - 列出 `models/loras` 下的第一级子目录（含数量，可多选），
  选择即保存；首页 Lora 区域**只展示**所选目录下的 LORA 示例，未勾选的 lora 不会出现在素材面板中。
  所选目录在 `models/loras` 里已不存在（被改名 / 写错）时直接忽略、不生成状态卡，需要时在弹窗里重选即可
- **访问时自动缓存** - 打开「Lora」目录或其子目录时，按文件 SHA256 查询 Civitai
  （`model-versions/by-hash`），后台下载该版本的全部示例图并写入提示词 sidecar；
  每次访问最多处理 20 个 LORA，已缓存（size/mtime 未变）的 LORA 自动跳过，
  被删除/更换的 LORA 缓存自动清理。失败项显示红色角标，可用「Retry Failed」重新入队

缓存结果落在 `gallery/lora_cache/`（只读素材源，与 presets 同机制）：**一个 LORA = 一个目录**，
目录内是多张 `example_NN` 示例图 + 同名 `.txt`（示例提示词）。素材面板中会出现「Lora」目录，
浏览、搜索、灯箱等全部能力可用；在 Lora 缩略图、灯箱或目录卡片上点 📤 会把该 LORA 的
相对路径（如 `detail/tweak.safetensors`）发送到画布上标准 `LoraLoader` 的 `lora_name` 参数
（目标菜单：选中节点优先，多目标弹下拉）。

「Lora」区域内提供**智能感知**筛选：勾选「工作流已用」后，只展示当前画布上 `LoraLoader` 节点
已使用的 LORA 目录（按 `lora_name` 匹配）。

## ⭐ 收藏（书签）

素材面板首页提供 **本地收藏** 与 **Civitai 收藏** 两个入口卡，收藏后端逻辑统一在 `bookmark.py`
（`bookmarks.json` 记录本地收藏，仅存路径信息，不复制文件）：

- **信息扩展按钮** - 任意素材缩略图右下角的「⋯」按钮弹出收藏菜单：**收藏本图**（记录素材完整路径）或
  **收藏所属目录**（把整个目录加入收藏，含自定义目录与 OSS 预设素材）。收藏卡与目录卡共用同一封面渲染：最多两张（竖/方图并排且顶部锚定、横图单张）
  （取自收藏内容前两张缩略图，纯音频则显示音频瓦片）
- **生成角色图（多视图）** - 图片卡的「⋯」菜单项：弹出小窗（复用九宫格分镜图同款弹窗，参考图按卡片大小显示 + 文件名确认），点「生成」后窗口内实时显示排队/生图进度，完成后直接预览结果图（点开看原图）、可用「打开输出目录」跳转。用 Qwen Image 2.1 以该人像为参考一键生成
  （头特写/正/侧/背）四视图角色设定图，按 1920×1080 请求输出（尺寸按 16 对齐），结果落
  `output/CharacterSheet/<日期>/`（素材库 **`CharacterSheet`** 主目录即此目录，同名文件跳过，可重复生成不重复占位），
  可直接拖入导演配方的 👤 角色参考图
- **新建导演配方** - 图片卡的「⋯」菜单项（多选操作条同款入口）：以该图为首帧新建 f2v 导演配方并打开编辑器（每段默认 5 秒）。子文件夹里的图先经 `copy_to_input` 落到 `input/` 根目录（按内容哈希去重），编辑器帧一律按 `subfolder=` 空解析
- **生成九宫格分镜图** - 图片卡的「⋯」菜单项：弹出小窗（参考图按卡片大小显示 + 文件名，确认用的就是这张）。小窗上方是
  **分镜故事**框（可手写），中间是**宫格技能**下拉（列出后端 `storyboard_grid_*` 技能，默认 `storyboard_grid_6`），下方是**简要故事 / 想法**框（可留空）：点「✨ LLM 生成分镜故事」只把简要故事（留空则只给格数）
  交给**所选宫格技能**（技能正文既是编剧指令也是生图模板；`<!-- @story-writer -->…<!-- @end -->` 区块只给 LLM 当编剧说明，进生图提示词前剔除）流式生成按 N 格逐格推进的故事**覆盖写入上方故事框**，可再编辑。
  这一步**不把参考图交给 LLM**（人物设定图会被模型当成"要描述的图"而反推）：改用 `storyboard_ref_detail` 把参考图的人物外形 + 服装先提取成文字，随简要故事一起交给编剧；生图那步仍照旧带参考图，外形与服装以 `<image1>` 为准。
  点「生成」后小窗**不关闭**：窗内显示排队/生图进度条（可「取消任务」），完成后原地出结果预览（点开看原图）；
  生图前先用 `storyboard_ref_detail` 技能对这张参考图跑一次受限视觉调用（只出人物外形 + 服装 1~2 句，不写分镜/场景），
  以 `【参考图人物与服装细节】…` 注入提示词做**文字锚定**（取不到就跳过，退回只有 `<image1>` 指代）；
  再用 Qwen Image 2.1 以该图为参考
  （提示词里以 `<image1>` 指代）按所选宫格技能生成 N 格分镜故事板（4=2×2、6=2×3、9=3×3，每格约 16:9，模板正文取自该技能的 `skill.md`），
  结果落 `output/StoryBoard/<日期>/`（素材库 **`StoryBoard`** 主目录即此目录，同名文件跳过）；点结果区的「打开输出目录」跳到该日期子目录。把这张宫格图
  拖进导演编辑器「🧩 宫格分镜图拆分」即按行优先切成 N 张关键帧（每格一镜、细白缝分隔、格内无文字）
- **图片编辑** - 图片卡的「⋯」菜单项：弹出小窗（图片在上、操作在下：上方是原图/编辑结果对比区，下方是编辑技能下拉 + 编辑指令输入框 + 状态/按钮）。默认使用 Qwen Image 2.1，可切换其他 `image_gen` 类技能；原图作为参考图传入，用户填写编辑指令后点「生成」出图；结果在原位显示「原图 | 编辑结果」窗帘对比（拖拽分割线；左侧原图、右侧结果）
  - **扩图** - 窗内开关：自动切到「Qwen Image 2.1 扩图」技能。在原图上拖框定四边留白量（拖动框体可平移、重分配四边留白；只向外扩，可选自由 / 1:1 / 16:9 / 2.35:1 等比例预设；画布超出可视区时整体自动等比缩小，边长上限为原图 4 倍）。**留白忠实按拖动算，不在没拖的轴上凑数**；出图走参考工作流 `▶▷Qwen-image21-功能流` 的「图像扩展」同一套算法：原图先归一化到 1MP、补灰边、画布再归一化到目标像素（两次都 32 对齐）后出图。目标像素数（MP）默认 1.5（与参考工作流一致），标签显示出图尺寸。提示词为空时预填默认触发词
- **本地收藏** - 打开首页「本地收藏」进入收藏板块，卡片封面同样取收藏内容前两张；点击卡片按记录的路径
  查找并打开源目录（源文件被移动/删除时给出提示），可随时 ✖ 取消收藏
- **C站收藏** - 首页「C站收藏」展示你在 civitai.com 收藏的模型（分页浏览 + 原比例封面，最多两张）：
  - **边下边开**：打开某个收藏模型时，示例图下载到第一张即可进入浏览，其余由后台继续缓存，完成后目录自动补齐
  - **启用 C 站收藏**（默认开启）：「Manage Directories」弹窗的 Civitai（C 站同步）区提供开关，
    关闭后首页入口与 `C站收藏` 目录不再加载（状态保存在 `gallery_settings.json` 的
    `civitai_bookmark_enabled`）
  - 与 Lora 板块一致：缩略图网格、灯箱（←/→ 翻页、缩放、全屏），以及把收藏保存为配方

## 实现细节（开发者）

### Civitai LORA 抓取与缓存
`gallery_lora.py` 负责后台抓取：打开「Lora」目录或其子目录时，按文件 SHA256 查询 Civitai（`model-versions/by-hash`），下载该版本全部示例图并写入提示词 sidecar；每次访问最多处理 20 个 LORA，已缓存（size/mtime 未变）的自动跳过，被删除/更换的缓存自动清理。缓存落在 `gallery/lora_cache/`：一个 LORA 一个目录，内含多张 `example_NN` 示例图 + 同名 `.txt` 提示词。

后端实现见 [architecture.md](architecture.md)（`gallery.py` / `gallery_lora.py` / `gallery_oss.py`），API 见 [api-routes.md](api-routes.md)。
