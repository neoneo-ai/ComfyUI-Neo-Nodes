# 短视频脚本（B 站 / 小红书 / 知乎）

三条 60 秒左右的录屏短视频，配 TTS 解说。解说词与画面操作一一对应，按钮名、节点名、
菜单名均与当前版本一致，录制时照「录屏操作」列点，不要临场改词。

## 通用规范

- **录制**：1920×1080，画布缩放调到节点名可读；鼠标移动放慢，关键点击前停 0.5 秒。
- **语速**：4.5–5.0 字/秒（约 270–300 字/分钟）。解说词按分镜表计时，超时删字幕句，不靠加速。
- **字幕**：每屏一行 ≤18 字。节点名在字幕用英文原名，解说词说中文名（解说「导演节点」，字幕 `NeoH3VideoDirector`）。
- **片尾统一 6 秒**：顶栏 🅝 菜单展开 → 定格 → 字幕「ComfyUI Manager 搜 Neo Nodes，重启即用」。三条共用同一片尾与同一 BGM。
- **不解说**：显存、步数、seed 数值等参数细节，画面带过即可，解说只讲「不用填」。

## 脚本一：一张宫格图，直接变成一条带声音的片子（70 秒）

**钩子**：外部生成的一张六格分镜图 → 在导演配方里拆分 → 逐段生成 → 一条含音频成片。画布上只有两个节点。

| 时间 | 录屏操作 | 解说词 | 字幕 |
|---|---|---|---|
| 0–6s | 先给成片 2 秒快闪，再切到素材库 `Pictures` 目录的六格分镜图 | 一张六格分镜图，直接变成一条带声音的片子。 | 一张宫格图 → 一条成片 |
| 6–16s | 加 `NeoH3VideoDirector` 节点，点右下角「＋ 新增导演配方」打开编辑器 →「📖 故事板分镜」页 →「🧩 宫格图故事板」卡片，把宫格图从素材库拖进卡片 | 加一个导演节点，点右下角的加号新增导演配方，打开编辑器。故事板分镜页里，宫格图故事板卡片选这张图，从素材库拖进去。 | ＋ 新增导演配方 📖 故事板分镜 → 🧩 宫格图故事板 |
| 16–28s | 切分方式选「自动检测」，点「✂️ 拆分到各段」；下方「各段对照」逐格出现，每格缩略图就是该段首帧 | 切分方式选自动检测，点拆分到各段。宫格按行优先切开，每一格成为这一段的首帧和分镜图，下面的各段对照逐格排好。 | ✂️ 拆分到各段 每格 = 该段首帧 · 行优先切格 |
| 28–40s | 源图右侧「全局故事参考」可手写整片故事走向 →「🎞️ 分镜时间线」页首行选生成模式与技能 → 保存 → 回画布，节点时间轴出现段块 | 右边这栏是全局故事参考，写整片的故事走向，可改写。时间线页选模式和技能，保存，回画布，节点时间轴就是这些段。 | 全局故事参考 🎞️ 分镜时间线 选模式与技能 |
| 40–54s | 点 ComfyUI「运行」，节点逐段生成；时间轴当前段琥珀色按比例增长、完成段绿满条，节点内预览面板实时出画面；悬停段块勾上它只跑勾选段 | 点运行，逐段生成。当前段琥珀色按比例增长，跑完的段变绿，节点里的预览面板实时出画面。想重跑某一段，悬停段块勾上它，只跑勾选的段。 | 逐段生成 琥珀=当前段 绿=已完成 · 勾选只跑勾选段 |
| 54–64s | 导演节点输出接 SaveVideo，播放成片，特写接缝处 | 最后拼成一个带音频的视频。连续性默认开着，上一段尾部二十来帧作为下一段开头参考，接缝六帧淡化。 | 单个含音频 VIDEO 接缝 6 帧淡化 |
| 64–70s | 画布全景：只有导演节点和 SaveVideo 两个节点，一屏装下；接片尾 | 一张宫格图，一个导演节点。装 Neo Nodes，重启即用。 | 两个节点，一条片子 |

**B 站标题**：`ComfyUI 一张六格分镜图，直接变成一条带声音的片子`
**封面文案**：`宫格图 → 成片`（大字）+ 小字 `导演配方里拆分 · 逐段生成`
**小红书标题**（≤20 字）：`ComfyUI 一张宫格图出成片`
**知乎标题**：`如何用一张分镜宫格图在 ComfyUI 里生成多段连续视频？`

**录制清单**
1. 宫格图：带分隔条或留白的分镜宫格图（外部生成），放进素材库 `Pictures` 目录以便拖入卡片。`generated_en_3.webp`（2×3 六格）是本次录制用的图；webp 不带 ComfyUI 元信息，「全局故事参考」需手写。
2. 画布只放 `NeoH3VideoDirector` + `SaveVideo`，其余节点清空。宫格拆分在配方的故事板分镜页里做，宫格图不上画布，`NeoGridSplit` 节点不参与本条流程。
3. 提前跑一次，让时间轴颜色变化（当前段琥珀按比例增长、完成段绿满条）与节点内实时预览在录制时真实出现。
4. 「✂️ 拆分到各段」点下去那一瞬间「各段对照」逐格替换，是这条视频的记忆点，给足 3 秒。
5. 成片接缝处留 3 秒静默，让画面自己说话。

## 脚本二：十二张参考图，一个节点管完（55 秒）

**钩子**：告别一排 `LoadImage` 节点；一句话 → AI 提示词 → 直接接视频/出图。

| 时间 | 录屏操作 | 解说词 | 字幕 |
|---|---|---|---|
| 0–6s | 快闪一张传统画布：一排 LoadImage 节点连线乱 | 十二张参考图，一个节点管完；一句话，直接出提示词。 | 一排 LoadImage？不要 |
| 6–18s | 加 `NeoRefGrid` 节点，工具条 −/+ 把槽位从 9 调到 12；左侧素材面板拖入 2 张，本地多选批量添加，OS 文件管理器拖 1 张进宫格；拖瓷砖重排，点瓷砖预览 | 参考图宫格节点，加减号调槽位，一到十二。素材面板拖进来，本地文件多选批量加，系统里的文件直接拖到宫格。瓷砖拖放重排。 | 🔲 Neo Reference Grid 槽位 1~12 · 拖放重排 |
| 18–30s | 加 `NeoPromptAgent` 节点，底部快捷框输入一句大白话，点 ✨，输出框出提示词文本 | 提示词不用连 CLIP。底部快捷框写一句大白话，点闪光，AI 生成提示词。宫格输出提示词和图，连线时槽位自动长出来。 | ⚡ Neo Prompt Agent 一句话 → ✨ 生成 槽位自动增长 |
| 30–42s | 在提示词里插入 `<Picture 1>`、`<Picture 2>` 标记；把宫格输出连到 H3 参考生视频节点，参考图槽位编号与宫格顺序对齐 | 提示词里用 Picture 1、Picture 2 指代第几张参考图，顺序就是槽位编号。接参考生视频，参考图最多九张。 | `<Picture 1>` = 第 1 槽 · 参考图 ≤9 |
| 42–55s | 保存配方（宫格作为主图片资产），再还原一次，宫格被优先填回；接片尾 | 保存配方时宫格作为主图片资产收集，还原时优先填回宫格。一句话加十二张图，就是一个可复用的配方。装 Neo Nodes，重启即用。 | 配方保存 → 宫格优先填回 |

**B 站标题**：`ComfyUI 一个节点管十二张参考图，一句话生成提示词`
**封面文案**：`12 槽参考图`（大字）+ 小字 `Reference Grid + Prompt Agent`
**小红书标题**（≤20 字）：`ComfyUI 参考图宫格太省事`
**知乎标题**：`ComfyUI 里如何用一个节点管理多张参考图并生成提示词？`

**录制清单**
1. 素材面板里备好 12 张风格统一的参考图（人物/服装/场景），拖入后宫格铺满好看。
2. 快捷框的大白话用真实短句，例如「雨夜霓虹街头，女特工回眸」，✨ 后输出文本要清晰可读。
3. 槽位从 9 加到 12 的动作要拍清楚（工具条加减号）。
4. 连线时输出槽 `image_1` → `image_12` 逐个露出，是这条视频的记忆点，给足 3 秒。

## 脚本三：社区下载的工作流满屏红节点，一键修好；缺的模型直接下（70 秒）

**钩子**：论坛下的工作流 → 满屏红节点 → 一键修复 → 缺模型直接下 → 断点续传。

| 时间 | 录屏操作 | 解说词 | 字幕 |
|---|---|---|---|
| 0–6s | 素材库 NeoDemo 目录点开内嵌工作流的社区图，灯箱「⤷ 导入工作流」载入画布；满屏红节点，顶栏 🅝 按钮亮起红点 | 从论坛下的 MiniMax H3 全能参考工作流，模型名是作者机器上的。导入画布，满屏红节点。一键，全修好；缺的模型，直接下。 | 社区工作流 = 满屏红节点 |
| 6–20s | 点 🅝 →「🔧 修复工作流」，确认框逐行显示：原路径红色删除线 → 候选新路径绿色 + 置信度百分比；切「严格/标准/宽松」三档；点「修复」，画布原地更新，节点位置不动 | 顶栏菜单亮起红点，点修复工作流。确认框里，原路径红色删除线，候选新路径绿色，带置信度百分比。阈值三档。点修复，画布原地更新，节点位置不动。 | 🅝 → 🔧 修复工作流 置信度百分比 · 三档阈值 |
| 20–34s | 挑一个匹配失败行，在「修复为」列手动选文件，勾「记住手动选择」；再演示一个模型压根没装的行，点行上的「📥 模型库」按钮，跳到模型库并预填搜索词与类别 | 匹配不上的，在修复为那一列手动选文件；勾上记住手动选择，下次同样的失效路径自动替换。模型压根没装，失效行直接给模型库按钮，预填类别和搜索词。 | 手动改选 · 记住映射 缺模型 → 📥 模型库 |
| 34–48s | 模型库：选源 ModelScope / Hugging Face，搜索仓库，选仓库，文件清单每条显示「文件名 [落盘类别] 大小」，磁盘已有的标「✓ 已存在」；选文件自动带出类别，子目录用下拉，预览路径 | 模型库里选源，双源都能搜，仓库里的模型文件列出来，每条带落盘类别和大小，磁盘已有的标已存在。选文件自动带出类别，子目录是下拉。 | 📥 模型库 双源搜索 · 自动归类落盘 |
| 48–60s | 点 ⬇ 下载，进度条 + 百分比 + 速度；中途点「取消」，状态显示「已取消（断点保留）」；再次点下载，进度从断点继续；下完提示并刷新清单 | 下载有进度条、百分比和速度。中途取消，断点保留，状态写着断点保留。再点下载，按 Range 续传，不重头开始。 | `.part` + meta.json 取消保留断点 · Range 续传 |
| 60–70s | 打开「📜 修复记录」表格（时间·来源·节点·原路径·修复结果），然后接片尾 | 修复记录存在本机，最多五十条，不上传。装 Neo Nodes，重启就能用。 | 修复记录仅存本机 |

**B 站标题**：`ComfyUI 社区工作流满屏红节点，一键修复 + 断点续传下载`
**封面文案**：`满屏红 → 一键修好`（大字）+ 小字 `修复工作流 + 模型库`
**小红书标题**（≤20 字）：`ComfyUI 社区工作流红节点一键修`
**知乎标题**：`ComfyUI 社区工作流的模型路径失效如何批量修复？`

**录制清单**
1. 社区工作流用 `python tools/make-community-workflow.py` 生成：拿真实社区工作流
   （MMH3/MiniMax H3 全能参考工作流，75 节点），把模型名换成作者机器上的原始权重名
   （fp16 / fp8），本机只有量化版，内嵌进 `input/NeoDemo/minimax-h3-community.png`。参考图与音频是程序画的抽象几何素材
   （机甲 / 异形 / 废墟 + 一段音），全部落在 `input/NeoDemo/`，素材库进这个子目录就只有安全素材。
   三行演示位：UNET 只差量化标记（90% 置信度），CLIP 相似度不够（手动改选 + 模型库按钮），
   VAE 本机没有（触发「📥 模型库」按钮）。录制前脚本会清掉上次留下的修复映射，保证每次都是满屏红节点。
2. 断点续传要拍真：下载一个较大文件，取消后状态文字「已取消（断点保留）」必须入画，再点续传时百分比从原处起跳。
3. 修复前后画布对比：红节点满屏 → 修复后干净，前后各留 2 秒，同机位不缩放。
4. 修复记录表格滚动一遍，突出「仅存本机，不上传」。
